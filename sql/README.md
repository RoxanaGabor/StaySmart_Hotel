# SQL Documentation – StaySmart Hotel Management System

This folder contains SQL artefacts supporting the StaySmart database project.

## Files
- `staysmart_schema.sql`  
  Auto-generated SQL export from SQLiteStudio containing the full database schema, data, triggers, views, and indexes.

- `example_queries.sql`  
  Representative SQL queries demonstrating joins, grouping, SQLite functions, views, and message output as referenced in the project report.

These files are provided for documentation and reproducibility purposes.
