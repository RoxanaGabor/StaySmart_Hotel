## StaySmart Hotel Management System

A proof-of-concept hotel management system developed using SQLite and Python Tkinter as part of the Advanced Database Systems module.

### Admin Login (Demo)
Username: admin  
Password: password123  

### How to Run
1. Ensure Python 3.x is installed
2. Open a terminal in the project root
3. Run:
   python python/app.py
4. Log in using the demo credentials

### Notes
- SQLite database: staysmart.db
- XML is used for flexible booking preferences
- Payment data is encrypted for demonstration purposes only
