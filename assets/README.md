# Assets – StaySmart Hotel Management System

This folder is reserved for application assets such as images or icons.

In the current prototype, the application uses native Tkinter components and
stores guest ID images directly within the SQLite database as BLOB data rather
than external image files. This design choice simplifies data management and
ensures guest identification data remains tightly coupled with the database
records.

The folder is included to demonstrate planned extensibility for future UI
enhancements.
